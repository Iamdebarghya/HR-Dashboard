# HR Analytics Dashboard | Advanced Excel

An interactive workforce reporting workbook built in Microsoft Excel. The dashboard is designed to help HR teams explore headcount, department mix, gender distribution, compensation and performance indicators.

## Business questions
1. How is the workforce distributed across departments?
2. How do employee counts vary by gender and department?
3. What do average, minimum, maximum and total salary measures show?
4. How can performance ratings be compared across workforce segments?

## Workbook capabilities
- Pivot-table based summaries
- Interactive slicers for department, gender and performance rating (where supported by the workbook version)
- KPI calculations for salary and headcount
- Charts for workforce composition and comparisons

## Files
- `HR_Dashboard .xlsx`: source Excel workbook

## How to use
1. Download the workbook from this repository.
2. Open in Microsoft Excel desktop for full PivotTable and slicer support.
3. Use the slicers to filter the dashboard and compare workforce segments.
4. Refresh PivotTables if you replace or extend the source data.

## Analysis approach
The workbook uses Excel PivotTables and charts to summarize employee-level records. Validate source column definitions and refresh the pivots before using the results for decisions. Any observations depend on the dataset version loaded in the workbook.

## Privacy
The workbook is a sample analytics artifact. Do not upload identifiable employee records or confidential HR data to a public repository. Use anonymized or synthetic records for demonstrations.
